# 📊 Ad Campaign Insights & Optimization Dashboard

This project analyzes simulated digital ad campaign data using Python and Jupyter Notebook to generate actionable insights and visualizations. It is designed to demonstrate key skills in data analysis, SQL-style logic, automation, and reporting — aligned with the expectations of client-facing analytics roles like Google gTech Ads.

---

## 🚀 Features

- Load and process ad campaign data (CTR, CPC, CPA)
- Grouped campaign insights using Pandas
- Identify top-performing and low-performing campaigns
- Bar charts for visual comparison of CTR and Conversions
- Ready for integration into Tableau or Looker Studio dashboards

---

## 🧠 Skills Demonstrated

- Data Analysis using Pandas
- Data Visualization using Matplotlib & Seaborn
- Performance Metric Computation (CTR, CPC, CPA)
- Python scripting & Jupyter Notebook presentation
- Business Insight Generation for Optimization

## 🧪 How to Run

1. Install dependencies:
    ```bash
    pip install pandas matplotlib seaborn
    ```

2. Clone this repository or download the files.

3. Place both files in the same directory:
    ```
    ad_campaign_data.csv
    Ad_Campaign_Insights_Dashboard_with_Charts.ipynb
    ```

4. Run Jupyter Notebook:
    ```bash
    jupyter notebook
    ```

5. Open the notebook and run all cells (Shift + Enter).
